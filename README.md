## 📌 About The Project

**Task Management website** is a modern web application designed to help users organize and manage their daily tasks efficiently.

Users can create, edit, delete, filter, and complete tasks while keeping track of their priorities and statuses through a clean and responsive interface.

---

## ✨ Features

### 📝 Task Management

* ➕ Create new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ☑️ Mark tasks as completed
* 🔄 Update task details
* 📅 Assign dates to tasks

### 🎯 Task Organization

* 🔴 High priority
* 🟡 Medium priority
* 🟢 Low priority
* 🔍 Filter tasks
* 📋 View all tasks
* 📆 View today's tasks

### 📊 Dashboard

* 📈 Total tasks statistics
* ⏳ Pending tasks count
* ✅ Completed tasks count
* 📅 Today's tasks
* 📊 Task overview

### 📱 Responsive Design

The application is fully responsive and optimized for:

* 💻 Laptop
* ▭ Tablet
* 📱 Mobile
